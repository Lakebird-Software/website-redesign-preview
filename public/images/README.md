# Image placement guide

The homepage currently uses CSS-created device/screen artwork as graceful placeholders.
Replace or enhance these with original, optimised images when ready.

Suggested files:
- `brand/lakebird-logo.svg` — original transparent company logo.
- `finly/finly-icon.png` — FINLY app icon.
- `finly/finly-dashboard.webp` — main dashboard screenshot.
- `finly/finly-analytics.webp` — analytics screenshot.
- `finly/finly-transactions.webp` — transactions screenshot.
- `gps-camera/gps-camera-icon.png` — GPS Camera app icon.
- `gps-camera/gps-camera-main.webp` — GPS-stamped photograph.
- `gps-camera/gps-camera-map.webp` — map/location screenshot.
- `gps-camera/gps-camera-report.webp` — PDF report screenshot.
- `filtra/filtra-icon.png` — Filtra app icon.
- `filtra/filtra-preview.webp` — approved UI preview.

Use WebP or AVIF for photographs/screenshots where practical. Keep original logos as SVG or transparent PNG.
